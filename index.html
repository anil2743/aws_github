Deployment process

From code to production.

STEP 01

Write code

Create or update website files on your computer.

STEP 02

Push to GitHub

Commit changes and push them to the configured branch.

STEP 03

Automate deployment

GitHub Actions transfers the updated website to EC2.

STEP 04

Serve the website

Nginx serves the latest deployed files to visitors.
